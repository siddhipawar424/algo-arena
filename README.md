## What is Algo Arena?

**Algo Arena** is a real-time competitive coding platform where developers **battle each other on Data Structures & Algorithms problems** in a live, timed environment.

It simulates:
- Technical interview pressure
- Competitive programming environments
- Real-world problem-solving under constraints

Think:
> **LeetCode + Multiplayer Gaming + Interview Simulation**

---

## Core Features

### Real-Time Coding Battles
- 1v1 live coding matches
- Synchronized problem delivery
- Instant result evaluation

### Smart Matchmaking System
- Room-based pairing
- Auto-match with similar skill levels
- Fast lobby-to-game transition

### Interview Simulation Mode
- Timed DSA challenges
- Difficulty-based rounds (Easy → Hard)
- Pressure-based evaluation system

### Live Scoring Engine
- Accuracy-based scoring
- Speed bonus system
- Winner declared instantly

### Real-Time Interaction
- WebSocket-powered live sync
- Opponent activity tracking
- In-game status updates

## System Architecture
Player Join → Matchmaking Queue → Room Creation
                ↓
Problem Assignment (Server Controlled)
                ↓
Real-Time Code Sync via WebSockets
                ↓
Live Submission Evaluation
                ↓
Score Calculation + Winner Declaration
